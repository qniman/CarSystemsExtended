# Car Systems Extended — чек-лист проверки

Перед началом: настройки мода → включить **Debug mode**. Панель слева вверху показывает состояние.

Отладочные клавиши: **F7** комплект сигнализации, **F4** комплект замков, **F6** редактор креплений, **F5** тест чирпа.
Клавиши брелка (меняются в настройках): **L** закрыть / охрана, **U** открыть / снять.

## 1. Детали и установка
- [ ] F7 спавнит 5 предметов: блок, сирена, 2 предохранителя, брелок
- [ ] F4 спавнит 2 активатора замков
- [ ] Детали поднимаются, носятся и бросаются как обычные запчасти
- [ ] Деталь у места крепления → значок сборки → ЛКМ ставит её на место
- [ ] Вдали от места крепления значка нет
- [ ] Активатор встаёт в любую из двух дверей, во вторую — только если она свободна
- [ ] Предохранитель вставляется в гнездо на блоке (и на установленном, и на лежащем)

## 2. Болты
- [ ] Ключ подсвечивает весь болт (шляпку и стержень)
- [ ] Неверный размер ключа не крутит (ShowBoltSize пишет, больше или меньше)
- [ ] Блок 7 мм, сирена 10 мм, активатор 6 мм
- [ ] Болт вращается вокруг своей оси и уходит внутрь при затяжке
- [ ] Трещотка работает, переключатель направления меняет затянуть/открутить
- [ ] Пока хоть один болт вкручен, деталь не снимается
- [ ] Все болты выкручены → ПКМ снимает деталь

## 3. Проводка и питание (wiring mess)
Провода прокладываются игровым инструментом **wiring mess**: поднеси его к точке → значок сборки и название → **Use** (F); потом к другой точке → **Use**. Use на той же точке отменяет.
- [ ] У блока предохранителей (под торпедой справа) есть точка ALARM FEED (чёрная коробочка с красной меткой)
- [ ] ALARM UNIT → ALARM FEED: питание; на обоих концах короткий красный хвостик провода с втулкой
- [ ] ALARM UNIT → ALARM SIREN / DOOR LOCK ACTUATOR / CHOKE SERVO / ALARM LED: сигнальный провод, чёрные хвостики
- [ ] Порядок любой: можно начинать с устройства, можно с блока
- [ ] Неподходящая пара (сирена → предохранители) не соединяется, щелчок
- [ ] Хвостики проводов на двери ездят вместе с дверью, длинных проводов через салон нет
- [ ] Устройство: DISCONNECT WIRE (RMB) отключает провод без инструмента
- [ ] Блок: DISCONNECT POWER (RMB) отключает питание
- [ ] Блок не снимается, пока к нему подключено устройство (UNPLUG ... FIRST)
- [ ] Снял аккумулятор → блок без питания, но провод остаётся; вернул аккумулятор → снова работает
- [ ] Панель `alarm power:` честно пишет, чего не хватает: болты блока / проводка / аккумулятор / предохранитель
- [ ] Всё собрано → сирена один раз чирикает (самотест)

## 4. Брелок
- [ ] Брелок в руке → надпись PRESS L TO PUT ON SATSUMA KEYS
- [ ] L → брелок исчезает из рук, на панели `fob on keys`
- [ ] Это нажатие L НЕ ставит машину на охрану
- [ ] Без ключей Сатсумы брелок не работает
- [ ] **Ключ вставлен в замок зажигания → брелок не работает** (L, U, H)
- [ ] Брелок достаёт до машины примерно на 60 м, дальше команды не доходят
- [ ] Без питания блока брелок не работает

## 5. Охрана и замки
- [ ] L при закрытых дверях и капоте → 1 чирп, 1 мигание поворотников, `alarm: Armed`
- [ ] L при открытой двери или капоте → 3 чирпа, охрана не включается, светодиоды быстро мигают секунду
- [ ] U → 2 чирпа, 2 мигания, `Disarmed`; если была тревога — 4 чирпа
- [ ] Поворотники мигают при выключенном зажигании
- [ ] Светодиод на блоке без охраны раз в 3 с мигает зелёным (есть питание)

### Выносной светодиод (ALARM LED, у лобового стекла, болт 5 мм, провод к блоку)
- [ ] Без охраны не горит
- [ ] Под охраной: одна вспышка каждые 1,5 с
- [ ] Под охраной, но какая-то дверь не заперта (нет активатора/провода): две вспышки
- [ ] Была тревога, пока тебя не было: три вспышки (до снятия с охраны)
- [ ] Во время тревоги: частое мигание
- [ ] Во время прогрева: горит постоянно
- [ ] Без провода или с ослабленным болтом не горит
- [ ] Светодиод на блоке повторяет те же сигналы красным
- [ ] Запертая дверь (`L` на панели doors) снаружи: надпись LOCKED, клик — щелчок, дверь не открывается
- [ ] После U дверь открывается с первого клика, модель двери реально распахивается
- [ ] Закрыл / открыл несколько раз подряд — двери не «прилипают»
- [ ] Изнутри запертой двери: UNLOCK DOOR → отпирает (второй клик открывает)
- [ ] Двери без активатора (или с ослабленным болтом / без провода) не запираются, охрана всё равно включается
- [ ] Звук активатора («тук») при запирании и отпирании

## 6. Срабатывание
Первые 3 секунды после постановки на охрану датчики не реагируют.
- [ ] Отпер дверь изнутри под охраной → сирена
- [ ] Толкнул машину (сдвинулась) → сирена
- [ ] Удар по машине (бросил предмет, наехал другой машиной) → сирена
- [ ] Повернул ключ в зажигании под охраной → сирена
- [ ] Открыл капот под охраной → сирена
- [ ] Сирена воет ~30 с, поворотники мигают постоянно, светодиод часто мигает
- [ ] Через 30 с сирена замолкает, машина снова под охраной
- [ ] U во время тревоги → сирена сразу замолкает, `Disarmed`
- [ ] Без сирены (не установлена / без провода) тревога только светом
- [ ] Во время тревоги отключил провод сирены → сразу замолкла; подключил обратно → снова воет
- [ ] Тревога началась без подключённой сирены, подключил во время тревоги → завыла
- [ ] Громкость: вблизи громко, уже через 10–20 м заметно тише, вдали еле слышно
- [ ] Во время тревоги брелок тоже тихо пищит трелью (пейджер), если ты в пределах ~140 м от машины
- [ ] Дальше ~140 м брелок молчит; при снятии с охраны или окончании тревоги трель прекращается
- [ ] Панель показывает `last trigger:` с причиной

## 7. Аккумулятор
- [ ] Под охраной заряд медленно падает
- [ ] При воющей сирене заметно быстрее
- [ ] Севший аккумулятор → блок без питания, брелок не работает

## 8. Сохранение
- [ ] Лежащие детали остаются на своих местах
- [ ] Установленные детали на месте, затяжка болтов та же
- [ ] Активаторы в своих дверях (левый слева, правый справа)
- [ ] Питание и провода подключены
- [ ] Брелок на ключах
- [ ] Сохранился под охраной → после загрузки машина под охраной, двери заперты, без самотест-чирпа

## 9. Редактор креплений (F6)
- [ ] Появляется призрак детали с розовой точкой
- [ ] Стрелки / PgUp / PgDn двигают, `,` `.` поворачивают, Shift — мелкий шаг
- [ ] Insert переносит точку туда, куда смотришь
- [ ] Home переключает места (на панели видно какое)
- [ ] Установленная деталь двигается вместе с точкой
- [ ] End пишет позицию в консоль и в mounts.txt

## 10. Автозапуск и прогрев
Клавиша **H** (брелок). Настройки мода → Remote start: температура прогрева (по умолчанию 60 °C) и предел времени (10 мин).
**F3** спавнит сервопривод подсоса.
- [ ] Брелок двусторонний: H → брелок пиликает «отправлено» (3 нотки вверх), через ~0,5 с машина реагирует
- [ ] Успешный запуск → брелок играет мелодию «завелась»
- [ ] Отказ или неудачный запуск → брелок низко гудит дважды
- [ ] Остановка с брелка → брелок 3 нотки вниз
- [ ] Блок без питания: брелок пиликает, но ответа нет
- [ ] H при включённой передаче → 3 чирпа, на панели `refused: not in neutral`
- [ ] H без ручника → 3 чирпа, `handbrake off`
- [ ] H с открытым капотом → 3 чирпа, `hood open`
- [ ] H на нейтрали с ручником: 1 мигание, включается приборка, стартер крутит
- [ ] Не завёлся за ~2,5 с → пауза 3 с → ещё попытка; после 3 неудач 3 чирпа, `did not start`
- [ ] Завёлся → 2 мигания, `remote start: Running`
- [ ] Двигатель работает без ключа в замке, температура на приборе растёт
- [ ] Дошёл до заданной температуры → глохнет сам, приборка гаснет, `warmed up to ...`
- [ ] Повторное H во время прогрева → глушит
- [ ] Включил передачу во время прогрева → глохнет, `put in gear`
- [ ] Под охраной: прогрев не вызывает ложную тревогу (вибрация), двери остаются запертыми
- [ ] Тревога во время прогрева → двигатель глохнет
- [ ] Передача управления: U, сел, повернул ключ → прогрев отпускает (`handed over to key`), двигатель продолжает работать на ключе
- [ ] Аккумулятор тратится на стартер (на сером аккумуляторе не заведётся)

### Сервопривод подсоса
- [ ] Ставится у карбюратора, болт 8 мм, провод к блоку
- [ ] При холодном пуске ручка подсоса на торпеде сама вытягивается
- [ ] По мере прогрева ручка уходит обратно (к 45 °C полностью)
- [ ] После остановки подсос в нуле
- [ ] Без сервопривода подсос не трогается: холодный двигатель заводится хуже

## 11. Почтовый каталог
**F2** (отладка) — доставить отправленные заказы сразу, не дожидаясь следующего дня.
- [ ] При первой загрузке рядом с игровым журналом запчастей лежит брошюра «autotarvike catalog» (в консоли сообщение)
- [ ] Смотришь на брошюру → READ CATALOG (RMB) → открывается страница, курсор виден, голова не крутится, игрок не ходит
- [ ] Галочки отмечают комплекты, внизу пересчитывается TOTAL (+35 mk доставка)
- [ ] ПКМ или CLOSE закрывает каталог, управление возвращается
- [ ] FILL IN ORDER FORM → перед тобой конверт, каталог закрывается
- [ ] Конверт в руке вдали от магазина: подсказка ORDER: POST BOX AT TEIMO'S SHOP
- [ ] С конвертом у почтового ящика Теймо: POST ORDER → ЛКМ → конверт исчез, звук, на панели `mail orders posted: 1`
- [ ] На следующий игровой день (или F2) на почте у Теймо лежит посылка
- [ ] Посылка: значок покупки и цена; без денег не берётся
- [ ] ЛКМ → деньги списаны, посылку можно поднять
- [ ] OPEN PARCEL (RMB) → посылка исчезает, детали заказа высыпаются рядом
- [ ] Сохранение: отправленный заказ, неоплаченная посылка на прилавке, конверт и брошюра переживают перезагрузку
- [ ] Брошюра не появляется второй раз после перезагрузки

## 12. Сброс мода
Настройки мода → Reset → **Reset Car Systems Extended** → подтвердить.
- [ ] В игре: все детали мода исчезают (лежащие и установленные), хвостики проводов пропадают
- [ ] Двери открываются, сирена молчит, поворотники не мигают, прогрев глушится
- [ ] Брелок снят с ключей (L/U/H ничего не делают)
- [ ] Рядом с журналом запчастей снова лежит брошюра
- [ ] Выйти без сохранения и загрузиться → старые детали не вернулись
- [ ] В главном меню: сброс срабатывает при следующей загрузке
- [ ] В папке настроек мода появляется резервная копия cse_save.bak-…
- [ ] «Нет» в окне подтверждения ничего не трогает

## 13. Дальность и передача управления после автозапуска
- [ ] Ответ машины на брелок (мелодия «завелась») слышен до ~140 м, хотя команда уходит только с ~60 м
- [ ] Двигатель прогревается → U → сел → вставил и повернул ключ: двигатель не глохнет, внизу экрана HOLD THE BRAKE PEDAL
- [ ] Держишь тормоз 2 с → включается настоящая аварийка: 2 мигания, щелчки реле в салоне, лампы на приборке; кнопка аварийки не двигается; надпись исчезает, `handed over to driver`
- [ ] Если аварийка уже была включена кнопкой, она остаётся включённой
- [ ] Не нажал тормоз 20 с → двигатель глохнет, `no brake confirmation`, приборка остаётся включённой (ключ повёрнут)
- [ ] Включил передачу без тормоза → глохнет, `put in gear without the brake`
- [ ] Повернул ключ обратно до подтверждения → двигатель глохнет как обычно, `key turned off`
- [ ] Повернул ключ во время прокрутки стартера → автозапуск отпускает, дальше обычный запуск ключом
