# Car Systems Extended — чек-лист проверки

Перед началом: настройки мода → включить **Debug mode**. Панель слева вверху показывает состояние.

Отладочные клавиши: **F7** комплект сигнализации, **F4** комплект замков, **F6** редактор креплений, **F5** тест чирпа.
Клавиши брелка (меняются в настройках): **L** закрыть / охрана, **U** открыть / снять.

## 1. Детали и установка
- [ ] F7 спавнит 5 предметов: блок, сирена, 2 предохранителя, брелок
- [ ] F4 спавнит 2 активатора замков
- [ ] Детали поднимаются, носятся и бросаются как обычные запчасти
- [ ] Деталь у места крепления → значок сборки → ЛКМ ставит её на место
- [ ] Вдали от места крепления значка нет
- [ ] Активатор встаёт в любую из двух дверей, во вторую — только если она свободна
- [ ] Предохранитель вставляется в гнездо на блоке (и на установленном, и на лежащем)

## 2. Болты
- [ ] Ключ подсвечивает весь болт (шляпку и стержень)
- [ ] Неверный размер ключа не крутит (ShowBoltSize пишет, больше или меньше)
- [ ] Блок 7 мм, сирена 10 мм, активатор 6 мм
- [ ] Болт вращается вокруг своей оси и уходит внутрь при затяжке
- [ ] Трещотка работает, переключатель направления меняет затянуть/открутить
- [ ] Пока хоть один болт вкручен, деталь не снимается
- [ ] Все болты выкручены → ПКМ снимает деталь

## 3. Проводка и питание
- [ ] Над плюсовой клеммой аккумулятора: CONNECT ALARM POWER (только при установленном блоке)
- [ ] ЛКМ → красный провод от клеммы к блоку; ПКМ отключает
- [ ] На установленной сирене / активаторе: CONNECT WIRE → чёрный провод к блоку
- [ ] Провод на двери тянется за дверью при открывании
- [ ] Блок не снимается, пока подключено питание (DISCONNECT POWER FIRST) или провода (DISCONNECT WIRES FIRST)
- [ ] Снял аккумулятор → питание пропадает, провод исчезает
- [ ] Панель `alarm power:` честно пишет, чего не хватает: болты блока / питание / аккумулятор / предохранитель
- [ ] Всё собрано → сирена один раз чирикает (самотест)

## 4. Брелок
- [ ] Брелок в руке → надпись PRESS L TO PUT ON SATSUMA KEYS
- [ ] L → брелок исчезает из рук, на панели `fob on keys`
- [ ] Это нажатие L НЕ ставит машину на охрану
- [ ] Без ключей Сатсумы брелок не работает
- [ ] Дальше ~50 м от машины брелок не работает
- [ ] Без питания блока брелок не работает

## 5. Охрана и замки
- [ ] L при закрытых дверях и капоте → 1 чирп, 1 мигание поворотников, `alarm: Armed`
- [ ] L при открытой двери или капоте → 3 чирпа, охрана не включается
- [ ] U → 2 чирпа, 2 мигания, `Disarmed`
- [ ] Поворотники мигают при выключенном зажигании
- [ ] Под охраной: светодиод на блоке редко мигает красным; без охраны не горит
- [ ] Запертая дверь (`L` на панели doors) снаружи: надпись LOCKED, клик — щелчок, дверь не открывается
- [ ] После U дверь открывается с первого клика, модель двери реально распахивается
- [ ] Закрыл / открыл несколько раз подряд — двери не «прилипают»
- [ ] Изнутри запертой двери: UNLOCK DOOR → отпирает (второй клик открывает)
- [ ] Двери без активатора (или с ослабленным болтом / без провода) не запираются, охрана всё равно включается
- [ ] Звук активатора («тук») при запирании и отпирании

## 6. Срабатывание
Первые 3 секунды после постановки на охрану датчики не реагируют.
- [ ] Отпер дверь изнутри под охраной → сирена
- [ ] Толкнул машину (сдвинулась) → сирена
- [ ] Удар по машине (бросил предмет, наехал другой машиной) → сирена
- [ ] Повернул ключ в зажигании под охраной → сирена
- [ ] Открыл капот под охраной → сирена
- [ ] Сирена воет ~30 с, поворотники мигают постоянно, светодиод часто мигает
- [ ] Через 30 с сирена замолкает, машина снова под охраной
- [ ] U во время тревоги → сирена сразу замолкает, `Disarmed`
- [ ] Без сирены (не установлена / без провода) тревога только светом
- [ ] Панель показывает `last trigger:` с причиной

## 7. Аккумулятор
- [ ] Под охраной заряд медленно падает
- [ ] При воющей сирене заметно быстрее
- [ ] Севший аккумулятор → блок без питания, брелок не работает

## 8. Сохранение
- [ ] Лежащие детали остаются на своих местах
- [ ] Установленные детали на месте, затяжка болтов та же
- [ ] Активаторы в своих дверях (левый слева, правый справа)
- [ ] Питание и провода подключены
- [ ] Брелок на ключах
- [ ] Сохранился под охраной → после загрузки машина под охраной, двери заперты, без самотест-чирпа

## 9. Редактор креплений (F6)
- [ ] Появляется призрак детали с розовой точкой
- [ ] Стрелки / PgUp / PgDn двигают, `,` `.` поворачивают, Shift — мелкий шаг
- [ ] Insert переносит точку туда, куда смотришь
- [ ] Home переключает места (на панели видно какое)
- [ ] Установленная деталь двигается вместе с точкой
- [ ] End пишет позицию в консоль и в mounts.txt

## 10. Автозапуск и прогрев
Клавиша **H** (брелок). Настройки мода → Remote start: температура прогрева (по умолчанию 60 °C) и предел времени (10 мин).
**F3** спавнит сервопривод подсоса.
- [ ] H при включённой передаче → 3 чирпа, на панели `refused: not in neutral`
- [ ] H без ручника → 3 чирпа, `handbrake off`
- [ ] H с открытым капотом → 3 чирпа, `hood open`
- [ ] H на нейтрали с ручником: 1 мигание, включается приборка, стартер крутит
- [ ] Не завёлся за ~2,5 с → пауза 3 с → ещё попытка; после 3 неудач 3 чирпа, `did not start`
- [ ] Завёлся → 2 мигания, `remote start: Running`
- [ ] Двигатель работает без ключа в замке, температура на приборе растёт
- [ ] Дошёл до заданной температуры → глохнет сам, приборка гаснет, `warmed up to ...`
- [ ] Повторное H во время прогрева → глушит, 1 чирп
- [ ] Включил передачу во время прогрева → глохнет, `put in gear`
- [ ] Под охраной: прогрев не вызывает ложную тревогу (вибрация), двери остаются запертыми
- [ ] Тревога во время прогрева → двигатель глохнет
- [ ] Передача управления: U, сел, повернул ключ → прогрев отпускает (`handed over to key`), двигатель продолжает работать на ключе
- [ ] Аккумулятор тратится на стартер (на сером аккумуляторе не заведётся)

### Сервопривод подсоса
- [ ] Ставится у карбюратора, болт 8 мм, провод к блоку
- [ ] При холодном пуске ручка подсоса на торпеде сама вытягивается
- [ ] По мере прогрева ручка уходит обратно (к 45 °C полностью)
- [ ] После остановки подсос в нуле
- [ ] Без сервопривода подсос не трогается: холодный двигатель заводится хуже
